# Audiophile E-commerce

This is an e-commerce project built with [Next.js](https://nextjs.org/), [Supabase](https://supabase.io/), [i18nexus](https://i18nexus.com/), [Zustand](https://zustand-demo.pmnd.rs/), [React Query](https://react-query.tanstack.com/), [Ant Design](https://ant.design/), [Tailwind CSS](https://tailwindcss.com/), [ESLint](https://eslint.org/), [Husky](https://typicode.github.io/husky/), and [Prettier](https://prettier.io/).

## Features

- User authentication and session management with Supabase
- Product listing, search, add, update and delete functionality
- User profile management
- Dark and light theme support
- Responsive design
- Optimized font loading with [`next/font`](https://nextjs.org/docs/basic-features/font-optimization)
- Internationalization with i18nexus
- Global state management with Zustand
- Data fetching and caching with React Query
- UI components with Ant Design
- Code quality tools: ESLint, Husky, and Prettier
